# API DeskHub

Все эндпоинты read-only (только `GET`), реализованы на чистом Django (`JsonResponse`), без DRF.
Формат ответа: JSON, `Content-Type: application/json`. Другие HTTP-методы возвращают `405 Method Not Allowed`.

Базовый префикс: `/api/`

Время слотов (`time_start`, `time_end`) и «сейчас» считаются по часовому поясу города коворкинга.
Слот, который уже начался (или начинается ровно сейчас), в выдачу не попадает.

---

## GET /api/coworkings/

Список коворкингов с опциональной фильтрацией. Результат отсортирован по `id`.

### Query-параметры (все необязательные)

| Параметр | Тип | Описание |
|----------|-----|----------|
| `city` | string | Название города (точное совпадение). Неизвестный город даёт пустой список |
| `place_type` | string | `Workplace` или `Meeting_room`. Оставляет коворкинги с активным местом такого типа |
| `date` | string | Дата `YYYY-MM-DD`. Оставляет коворкинги со свободным, ещё не начавшимся слотом на эту дату (при заданном `place_type` учитываются только места этого типа) |

Параметры можно комбинировать.

### Пример запроса

```
GET /api/coworkings/?city=Владивосток&place_type=Workplace&date=2026-09-01
```

### Пример ответа `200 OK`

```json
{
  "results": [
    {
      "id": 1,
      "name": "Space Hub",
      "city": "Владивосток",
      "address": "Пр. Космонавтов, д 25",
      "work_time_start": "10:00",
      "work_time_end": "19:00"
    }
  ],
  "count": 1
}
```

### Ошибки

- `400 Bad Request`: недопустимый `place_type`:
  ```json
  {"error": "Недопустимый place_type. Варианты: ['Workplace', 'Meeting_room']"}
  ```
- `400 Bad Request`: неверный формат `date`:
  ```json
  {"error": "date должен быть в формате YYYY-MM-DD"}
  ```

## GET /api/places/{place_id}/slots/

Свободные слоты конкретного места на дату, отсортированные по времени начала.

### Path-параметры

| Параметр | Тип | Описание |
|----------|-----|----------|
| `place_id` | int | ID места |

### Query-параметры

| Параметр | Тип | Описание |
|----------|-----|----------|
| `date` | string | `YYYY-MM-DD`. Если не указан, берётся текущая дата по времени коворкинга |

### Пример запроса

```
GET /api/places/5/slots/?date=2026-09-01
```

### Пример ответа `200 OK`

```json
{
  "place_id": 5,
  "place_name": "Рабочее место A1",
  "capacity": 1,
  "date": "2026-09-01",
  "free_slots": [
    {"id": 101, "time_start": "10:00", "time_end": "11:00"},
    {"id": 102, "time_start": "11:00", "time_end": "12:00"}
  ]
}
```

Если подходящих слотов нет, `free_slots` равен пустому списку.

### Ошибки

- `404 Not Found`: место не найдено или неактивно:
  ```json
  {"error": "Место не найдено"}
  ```
- `400 Bad Request`: неверный формат `date`:
  ```json
  {"error": "date должен быть в формате YYYY-MM-DD"}
  ```

## GET /api/reservations/{reservation_id}/status/

Статус конкретной брони. Доступно только владельцу.

### Path-параметры

| Параметр | Тип | Описание |
|----------|-----|----------|
| `reservation_id` | int | ID брони |

### Авторизация

Нужна активная сессия (та же cookie, что и на сайте).

### Пример ответа `200 OK`

```json
{
  "id": 42,
  "status": "awaiting",
  "status_display": "Ожидает",
  "amount_people": 2,
  "place": "Переговорная B2",
  "created_at": "2026-08-20T14:03:11"
}
```

Возможные значения `status`: `awaiting`, `approved`, `declined`, `cancelled`, `completed`.
`place` равен `null`, если слот брони был удалён.

### Ошибки

- `401 Unauthorized`: запрос от неавторизованного пользователя:
  ```json
  {"error": "Требуется аутентификация"}
  ```
- `404 Not Found`: брони с таким ID нет **или** она принадлежит другому пользователю. Эти случаи
  намеренно не различаются, чтобы перебором ID нельзя было узнать, какие брони существуют:
  ```json
  {"error": "Бронирование не найдено"}
  ```

## Общие правила

- Формат дат в запросах: `YYYY-MM-DD`. Время слотов в ответах: `HH:MM`. Полные даты-время
  (`created_at`): ISO 8601.
- HTTP-коды:
  - `200`: успех
  - `400`: некорректные параметры запроса
  - `401`: требуется аутентификация
  - `404`: ресурс не найден (или недоступен текущему пользователю)
  - `405`: метод не поддерживается (разрешён только `GET`)
